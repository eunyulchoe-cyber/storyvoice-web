      주인공 정하기

      8장 그리기

        📚 내 그림책

        아직 만든 그림책이 없어요.

          녹음과 키는 이 기기에만 저장돼요. 무료 ‘기기 안에서’ 방식은 목소리가 기기 밖으로 나가지 않아요. 실시간 받아쓰기는 브라우저 회사 서버(Chrome은 Google)로 음성이 갈 수 있어요.

          짧은 영상

          아직 영상이 없어요.

          그림 8장과 낭독으로 세로 영상(MP4)을 만들어요. 인터넷이 없어도 이 기기에서 만들어져요.

          부모 확인

          부모 설정

          무료 키 두 개(Groq, Hugging Face)만 넣으면 받아쓰기부터 그림까지 무료로 쓸 수 있어요.

          없음

          빠르고 정확한 받아쓰기 + 장면 자동 나누기. 만들기: console.groq.com 가입 → API Keys → Create API Key

          없음

          그림 그리기(하루 무료 GPU 시간). 만들기: huggingface.co 가입 → 이메일 인증 → Settings → Access Tokens → New token(Read)

          유료 키(선택) — 쓴 만큼 키 주인에게 청구
          없음
          없음

          키는 이 기기 안에 암호화해 저장하고, 쓸 때 기기에서 해당 회사로 바로 보내요. StoryVoice 서버로는 가지 않아요.
